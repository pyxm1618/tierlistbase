# TierListBase 环境与发布手册

> 状态：CURRENT MAINTENANCE GUIDE
> 最近同步：2026-10-23

这个文件名由当前 release gate 直接读取，因此保留。内容只描述当前 TierListBase，不再承担旧 `creat-web` starter 教程职责。

## 1. 本地环境

固定使用 Bun 1.3.14。

```bash
bun install --frozen-lockfile
bun run dev
```

数据库相关开发使用 PostgreSQL 16。集成测试必须使用可丢弃的 `TEST_DATABASE_URL`，不能指向生产数据库。

## 2. 当前配置事实源

- 站点身份：`src/config/site.config.ts`
- 路由/SEO：`src/config/routes.config.ts`
- 功能开关：`src/config/features.config.ts`
- 法律/provider：`src/config/legal.config.ts`
- Vanguard：`src/config/vanguard.config.ts`
- Vanguard runtime：`src/config/vanguard-runtime.config.ts`
- Cloudflare runtime：`wrangler.jsonc`
- CI/deploy：`.github/workflows/ci.yml`

不要从旧 V1 任务描述推断当前配置。

## 3. 常用验证

```bash
bun run format:check
bun run lint
bun run typecheck
bun run test:unit
bun run test:integration
bun run test:contract
bun run db:verify
bun run verify:security
bun run verify:seo
bun run build
bun run build:vinext
bun run test:e2e
bun run verify:performance
```

按任务范围运行最小相关集；合并前以 CI 为最终仓库级 gate。

## 4. 数据库

迁移只能通过 Drizzle 正常生成：

```bash
bun run db:generate
bun run db:verify
```

不使用 production schema push，不把测试数据库地址复用到生产。

## 5. Production

当前 production：

- canonical: `https://www.tierlistbase.com`
- branch: `main`
- deploy: GitHub Actions -> Vinext -> Cloudflare
- database: Neon PostgreSQL
- auth: Google OAuth
- email: Resend
- Vanguard storage: Cloudflare R2
- Vanguard moderation: Cloudflare Workers AI

当前不是 Vercel production deployment。

## 6. 发布

生产 deploy 由 `.github/workflows/ci.yml` 自动控制，只从 push 到 `main` 触发。deploy job 会再次确认 workflow SHA 仍是 current main，防止旧 workflow 覆盖更新版本。

具体上线检查见：

- [上线检查清单](运维/上线检查清单.md)
- [故障处理](运维/故障处理.md)
- [密钥轮换](运维/密钥轮换.md)

## 7. 当前禁用能力

Commerce、subscriptions、credits 当前 production 均关闭。仓库仍保留平台能力和对应安全 verifier，因此不要把“代码存在”理解为“产品已启用”。

若要启用，必须走独立任务并先满足 [交易与积分](运维/交易与积分.md) 与 [Waffo 合约与验收](参考/waffo-合约与验收.md) 的 gate。
