## 如果未来要启用

必须作为独立产品/工程任务重新验收，不允许仅翻一个 feature flag。

至少要求：

1. 明确真实产品、价格、币种、权益与退款政策。
2. 完成 Waffo 商户/店铺/product/webhook 等真实资源验证。
3. 满足 [Waffo 合约与验收](../参考/waffo-合约与验收.md)。
4. 重新检查 checkout、webhook、subscription、refund、fulfillment、credits 的相关 integration/contract tests。
5. 明确 worker/定时恢复机制和生产凭据。
6. 更新法律文本与上线检查。
7. 经过 production release gate。

在正式启用前，不运行真实支付写入，不创建“为了验收而存在”的生产商品，也不把 dormant capability 写进用户侧产品承诺。
